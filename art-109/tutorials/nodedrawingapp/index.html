Node Drawing App

Build a colorful network by placing nodes, dragging them around, and connecting them into shapes, maps, constellations, or diagrams.

Mode

0 nodes 0 links
  1. Click empty space to add a node.
  2. Drag nodes in Add / Move mode.
  3. Use Connect mode, then click two nodes.
  4. Use Erase mode to remove a node or link.

Add / Move mode: click the canvas to add nodes.
